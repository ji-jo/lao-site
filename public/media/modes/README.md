# Mode preview videos

The live files are stored one directory above this note:

- `../animatron-demo.optimized.mp4` — appears inside the Animatron CRT, then expands into the Prussian-blue viewport stage.
- `../stopmotion-demo.optimized.mp4` — slides upward and overlaps the Animatron video later in the same pinned sequence.

Export requirements:

- Animatron aspect ratio: 1:1
- Stop Motion aspect ratio: 1:1 or 4:3; the layout reads the MP4 dimensions automatically
- Codec: H.264 video in an MP4 container
- Audio: optional; the website plays both previews muted for reliable autoplay
- Recommended dimensions: 1080×1080
- Keep each file reasonably small for mobile delivery (ideally under 8–12 MB)
- Enable fast-start metadata when exporting so playback can begin before the entire file downloads
